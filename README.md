## Desafio 2 — Site da ONG com CSS

Nesta etapa, apliquei CSS3 ao site da ONG Parceiros do Amanhã, desenvolvido inicialmente em HTML. O objetivo foi criar uma apresentação visual consistente e facilitar a navegação pelas páginas.

### Páginas

- `index.html`: apresentação da organização.
- `projetos.html`: projetos, voluntariado e campanhas de doação.
- `cadastro.html`: formulário de interesse em voluntariado.

### Estilos

Os arquivos CSS estão na pasta `styles`:

- `index.css`
- `projetos.css`
- `cadastro.css`

### Conceitos aplicados

- Cores, tamanhos de texto e espaçamentos definidos com variáveis CSS.
- Flexbox para alinhar elementos do cabeçalho e da navegação.
- Grid para organizar os cartões de projetos.
- Media queries para adaptar o layout a telas menores.
- Estilos para campos, grupos e botão do formulário.

### Como visualizar

Abra o arquivo `index.html` no navegador. Use o menu da página para acessar projetos e cadastro.
